# Portal components

- Meditation artwork is mapped by stable track ID and shared by the library, featured track and player; this preserves each track’s visual identity across views.
- Prayers share one catalog/player; BRT daily highlights rotate morning/day/night on entry, preserving playback.
- Prayer lyrics use cue-relative progress and measured visible bounds for long-line scrolling; this keeps all words readable without shrinking text or moving playback controls.
- In-App Movement join is one tap using the profile name, with the role chosen by explicit button; the manual form remains only as fallback when no name exists, keeping consent explicit without friction.
